# 织云系统 · 应用台账与资产控制台

面向多团队的应用资产管理系统：**应用台账**（全生命周期登记）+ **资产控制台**（分布、变更、风险红点、**实例健康告警**）+ **环境管理**（每应用自定义环境、发布窗口、节假日封网）+ **应用健康**（实例存活/掉线/重启频率分级）+ **配置档案**（按应用×环境管理配置项、密文管控、环境对比、版本回滚）+ **变更留痕**（配置逐键流水、环境窗口与实例健康事件、时间窗查询）+ **权限与交接**（四类角色、业务线×环境两级可见范围、密文权/编辑权分离、应用归属交接、权限变更留痕、并发编辑乐观锁冲突）。

## 一键启动

```bash
docker compose up -d --build
```

访问 http://localhost:8016 。首次启动自动建库并写入初始数据（4 条业务线、10 个账号、24 个应用，覆盖 在研/上线/维保/下线 全部状态，含缺负责人 / 缺环境变量的红点样例，以及授权与交接留痕样例）。

本地开发（不用 Docker）：

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8016
```

## 角色与权限模型

四类角色：**平台管理员 / 业务线负责人 / 应用负责人 / 只读观察者**。

- **可见范围按 业务线 × 环境 两级收窄**（`user_grants`，环境取 `*` 表示整条业务线）。典型样例：钱一只被授予「用户增长·生产」、周婷只被授予「数据平台·生产」，其他业务线/环境一律不可见。
- **应用归属**：应用负责人对**本人负责的具体应用**全部环境可查看、可编辑（密文仍须单独授权）；环境级授权则对该业务线下所有应用生效。
- **密文查看权与配置编辑权分开授予**：有编辑权不蕴涵明文权，有明文权不蕴涵编辑权。只读观察者角色封顶，永远不可编辑（即使误授编辑权，服务端也拒绝）。
- **越权不静默**：访问范围外业务线/环境返回 **403 错误态页面（非空白页）**，并说清是缺业务线范围、缺环境范围还是缺某项权限；无权账号的编辑/回滚/看明文按钮置灰并给出原因。

### 权限与交接

- **授权/收权**：平台管理员可管任意业务线，业务线负责人只限本业务线；可对某账号在「业务线 × 环境」上独立授予 配置编辑权、密文查看权（配置脱敏查看随授权开放）。**只有平台管理员能调整账号角色**。
- **应用归属交接（离职/转岗）**：交接的是应用归属与配置管理权限——**配置项、历史版本、密文与全部逐键留痕随应用一并移交**（数据挂在 app_id 上，无需搬动）；交接记录写清**交接前负责人 → 交接后负责人、发起人、时间、备注**，同时写入该应用变更日志与权限留痕。普通信息编辑不允许静默改负责人，必须走交接流程。
- **权限变更本身留痕**：授权、收权、角色调整、交接全部写入「权限变更留痕」，可在「权限与交接」页查询。

### 并发编辑冲突（同一账号两个浏览器）

配置保存与回滚都带 **`expected_version` 乐观锁**（打开编辑时的当前版本号）。服务端发现版本已被他人（或同账号另一会话）推进时返回 **409**，并携带：服务器当前版本号、对方操作人/时间/备注、以及「基线版 → 服务器当前版」的逐键差异。前端弹出冲突框让用户选择：

- **放弃我的改动**，刷新到最新版；或
- **在最新版基础上重新合并**：对方没动的键自动带上我的改动，双方都改过的键保留服务器值并标红，逐项确认后再保存。

绝不允许后来者静默盖掉前一个改动。

## 功能与规则

- **应用台账**：应用挂所属业务线、负责人、集群、环境（开发/测试/预发/生产）、生命周期状态；列表支持业务线 + 负责人 + 环境 + 状态 + 关键字组合筛选（结果按可见范围收窄）。
- **生命周期状态机**：`在研 → 上线 → 维保 → 下线`，只能向前流转；**下线为终态**，状态与所有信息（含环境变量、配置档案）只读。状态回退会被拦截并返回具体原因。
- **唯一性**：同一业务线下应用名不能重复（创建/改名均校验，返回 409 及原因）。
- **资产控制台**：各业务线应用数分布（按状态分段）、近 7 天有变更的应用、环境变量缺失 / 缺失负责人的红点提醒（均按可见范围统计），并在顶部直接冒出**实例健康告警**（掉线实例逐条列出 业务线×应用×环境，频繁/偏多重启环境分组）。
- **变更留痕**：创建、信息变更、状态流转、环境变量修改、应用交接均写入应用变更日志。

### 环境管理与发布窗口

开发 / 测试 / 预发 / 生产**不是写死的**：环境是每个应用下的一张注册表（`app_environments`），业务线可以在应用内新增自定义环境（如灰度 `gray`、预演 `pre-prod`），新建应用自动开通四个标准环境。

- **发布窗口按环境单独设置**：一周中哪几天（周几多选）、每天哪段时间（HH:MM–HH:MM）允许发布；也可设为全时段不限。
- **节假日封网**：给某个环境登记封网日期（如 10/1 国庆），即使当天是发布日也整天关闭发布，可逐日解除。
- **窗口外拦截上线**：配置保存与回滚都是上线动作，窗口外服务端一律 **409 拒绝**，响应不只给灰色按钮，而是说清原因（今天封网 / 今天不是发布日 / 窗口已于 18:00 关闭）并明确给出**下一次开放发布的时间**（自动跳过其间的封网日）；每次拦截本身也写留痕。
- **删除环境先清点挂载**：环境上若还挂着配置项、配置历史版本、运行实例，或它是应用当前登记的所属环境，删除一律 **409 拒绝**，并逐项列出"挂在什么上、各多少个"；空环境才允许删除。
- 窗口规则改动、封网日增删、环境增删全部进「变更留痕 → 环境与健康留痕」。

### 应用健康

每个环境下纳管实例（`app_instances` + `instance_events` 事件流）：

- 每环境汇总**实例总数、存活数、掉线数、近 24 小时重启次数、最后重启时间**；实例维度展示累计重启次数、近 24h/7 天重启次数、最后存活时间、掉线时长。
- **频繁重启与正常重启分级区分**：近 24 小时重启 ≥5 次判为「频繁重启」（红），≥2 次或近 7 天 ≥7 次判为「重启偏多」（黄），否则为正常；"一天重启二十次"与"半个月重启一次"在列表与作战台上颜色、数字明显不同。
- **掉线不用逐个应用翻**：资产作战台顶部「实例健康告警」直接列出全部掉线实例（业务线 · 应用 · 环境 · 实例名 · 掉线时长），点击直达该应用该环境；「应用健康」页可按 全部异常 / 掉线 / 频繁重启 / 重启偏多 / 健康 与业务线筛选。
- 实例的**登记 / 重启 / 掉线 / 恢复**写事件流并同步留痕，可在留痕页按应用、环境、类别、时间窗查询与导出 CSV。

### 配置档案

配置项按 **应用 + 环境**（开发/测试/预发/生产）管理，每个配置项包含：键、值、类型（字符串/数字/布尔/JSON，服务端强校验）、生效范围（全局/集群/灰度）、是否密文。

- **密文管控（服务端强制）**：密文在档案、环境对比、版本快照、留痕、CSV 导出中**一律脱敏**（`••••••••`），明文不随列表下发；查看明文只能调 reveal 接口，必须具备该 业务线×环境 的**密文查看权**且填写不少于 5 个字的业务理由，**理由为空/过短由服务端拒绝（400）**；每次查看逐条写留痕。
- **环境对比**：任选两个**可见**环境一键 diff；密文差异只提示不同、不泄露明文；无第二个可见环境时给出说明。
- **版本与回滚**：每次保存生成全量快照版本（无变化不产生空版本）；回滚 = **追加一个新版本**，旧版本与历史留痕原样保留。保存/回滚均带乐观锁，冲突走 409 取舍流程。
- **只读约束**：应用下线（终态）后，配置档案不能编辑、不能回滚；无编辑权账号同样被拦下并说明原因。

### 变更留痕

- 配置的**每次**改动（新增/修改/删除/回滚/查看明文）都有逐键流水：应用、环境、配置键、改前值、改后值（密文脱敏）、操作人、时间、理由/备注。
- 支持按 **应用 / 业务线 / 环境 / 动作 / 起止日期** 组合查询（强制限定可见范围，越权 403）。
- 一键**导出差异清单 CSV**（带 UTF-8 BOM，密文列同样脱敏）。

## 目录结构

```
app/
  main.py            # FastAPI 入口与台账/控制台路由（按权限收口，控制台含健康告警）

  permissions.py     # 角色/业务线×环境范围/密文权与编辑权分离/权限留痕（兼容自定义环境键）
  config_service.py  # 类型校验/快照版本/diff/回滚/乐观锁冲突/审计查询/CSV
  env_service.py     # 每应用环境注册表/发布窗口判定（周几+时段+节假日+下次开放扫描）/
                     # 删除挂载清点/实例健康分级（24h/7d）/作战台告警/环境健康留痕
  routers/config.py  # 配置档案 & 配置留痕 API（环境按应用注册表校验 + 发布窗口卡口）
  routers/admin.py   # 角色/授权收权/应用交接/权限留痕 API（自定义环境授权）
  routers/ops.py     # 环境管理/发布窗口/节假日/实例健康/环境与健康留痕 API
  db.py              # SQLite 表结构、四角色常量、旧库平滑迁移（放宽环境枚举 CHECK + 回填环境）
  seed.py            # 初始数据（环境窗口/国庆封网/掉线实例/频繁重启/灰度自定义环境样例）
  static/            # 前端（原生 JS，无构建步骤）：环境窗口弹窗、应用健康页、作战台告警、留痕双 tab
docker-compose.yml
Dockerfile
```
